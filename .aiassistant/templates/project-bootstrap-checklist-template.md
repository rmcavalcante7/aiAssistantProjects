# Project Bootstrap Checklist

## Objective

Validate that a new project has the minimum structure required to start safely.

## When to use

Use at the beginning of a project instantiated from this repository.

## Items

- [ ] The project type is explicit: automation, API, pipeline, library, or package.
- [ ] `CURRENT_CONTEXT.md` exists or bootstrap is intentionally still in progress.
- [ ] Main flows are described at a high level.
- [ ] Known integrations are listed.
- [ ] Important constraints are captured.
- [ ] A README strategy has been selected: product or operational.
- [ ] Required runbooks for the chosen project type are known.

## Notes

Add project-specific bootstrap checks when needed.
