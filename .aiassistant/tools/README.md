# Tools

This directory stores repository-local support scripts for `.aiassistant` maintenance.

Tools are executable helpers. They are not a source of truth.

Use this directory for:

- validating wikilinks;
- exporting derived graph data;
- checking repository governance rules that can be automated.

Do not use this directory for:

- architectural decisions;
- runtime context;
- runbooks;
- checklists;
- project-specific documentation.
