# Architectural Decisions

This directory stores accepted or proposed decisions for the SDK operating
system.

Use decisions for constraints that must be preserved over time:

- public API compatibility;
- package and versioning strategy;
- release workflow;
- documentation policy;
- dependency strategy;
- integration boundaries;
- repository governance.

Related governance:

- [[CURRENT_CONTEXT]]
- [[WIKILINK_RULES]]
- [[REPOSITORY_GUIDELINES]]

## Required Structure

Each decision should include:

- title;
- status;
- context;
- decision;
- alternatives considered;
- consequences;
- related files.

Accepted decisions must be followed unless explicitly superseded.
